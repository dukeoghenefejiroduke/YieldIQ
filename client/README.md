# AgroVoice Client

This is the frontend application for the **AgroVoice** AgriFinTech platform. It is built with **React**, **TypeScript**, and **Vite**.

## Key Features
*   **Offline-First:** Uses Dexie.js for robust local data storage and synchronization.
*   **Reactive Dashboard:** Real-time credit scoring and KPI tracking.
*   **Multilingual:** Supports Hausa, Yoruba, Igbo, Pidgin, and English.
*   **Weather Alerts:** Proactive risk notifications based on localized climate data.

## Development
- `npm run dev`: Starts the development server.
- `npm run build`: Builds the production assets.
- `npm run test`: Runs the test suite.
